App name: War Room Bot; bundle identifier: com.equinix.warroombot
Install path: /Applications/War Room Bot.app; private data: ~/WarRoomBot

Behavior:
- Calling options > Zoom Contacts + phone selects the roster name in Zoom's Contacts tab,
  sends one invitation, then calls the same on-duty row's phone without waiting for acceptance.
- Name matching ignores case and surrounding spaces, requires one exact displayed-name match,
  and refuses missing or ambiguous contacts. No email message is sent.
- Ordinary Contacts failure is recorded while the phone call proceeds. Stop interrupts the sequence.
- Test mode uses only the user-entered test phone and optional separate test contact name.
- The invited contact's fresh arrival can be correlated for three minutes after escalation finishes
  to avoid triggering another call. This display-name association is not authenticated identity.
- Existing private roster, settings and logs are preserved. Saving Calling options does not start calls.

Update using the verified app ZIP:
1. Stop the watcher and quit War Room Bot.
2. Run tools/prepare_app_update.py with --archive or --archive-url and the published --sha256.
3. The tool checks the digest, signature and visible window of a clean replacement and saves an
   original backup. It never writes Applications; Finder handles replacement and authentication.
4. In the revealed folder, drag War Room Bot.app onto Applications and choose Replace.
5. Run the printed final verification command, then open the app from Applications.
6. Choose Update / Repair and wait for Installation: ready.
7. Choose Calling options > Go, select Zoom Contacts + phone, then Save.
8. Make roster names match Zoom Contacts and enter phone numbers as Text with + and country code.
9. Preview on-duty roster, then Dry run: roster. Start: roster enables live calls after confirmation.
   Start the watcher before a new visitor joins; people already present form its baseline.

This update uses the Finder clean-copy method that worked on the target Mac. No live call or
Zoom invitation was performed during development. Real Contacts behavior still needs verification
on the target Mac. The app uses ad-hoc integrity signing, not Developer ID notarization.
