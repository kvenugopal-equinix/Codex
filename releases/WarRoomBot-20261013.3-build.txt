Changed behavior:
- Start: roster and Start: test number now include Phone only / Zoom Contacts + phone.
  The separate Calling options action is removed. Existing preferences only preselect visible controls.
- Test start opens with a blank phone every time. Contacts + phone additionally requires a test contact name.
  Roster start automatically uses the selected on-duty engineer's roster name and phone.
- Preview and launch receive the same explicit per-run choices. No saved settings are changed.
  Cancel starts no watcher. Status reports the active worker's route, not the current saved configuration.
- A successful Contacts invitation can report Accessibility error -25200. That is a generic system error,
  not proof that the action failed or permission is missing. The subsequent meeting Invite opener now
  observes the actual window before retrying. An open dialog continues to phone setup without a repeat.
- Opener retries are bounded and require readable closed-window observations. Unreadable state stops.
  Contacts submission and the phone Call button each remain single attempts.
- Roster mode reloads the file and reevaluates shifts/timezones/priority on each new visitor escalation.
  Shift changes and saved destination/shift edits need no restart; they do not trigger a call themselves.
  Support recognition is loaded at startup; restart after adding new people who must be recognized as support.
