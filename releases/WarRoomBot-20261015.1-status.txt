The ZIP contains the complete 20261015.1 source and a guarded Python-only update
for the known installed 20261013.3 Mac app. It contains no private .env, roster,
logs, or virtual environment. The existing app and signed helper stay in place.
The old native window keeps its 20261013.3 version display and cannot gain the
new button through a Python-only update. The update opens a separate Mac save
dialog; the bot creates the workbook in the selected Finder location.

On the Mac, stop the watcher, quit War Room Bot, and put the source ZIP in
~/Downloads. Put Update-War-Room-Bot-20261015.1.command beside it and run:

  bash "$HOME/Downloads/Update-War-Room-Bot-20261015.1.command"

The launcher verifies the ZIP checksum, applies the Python update, and opens
the workbook location picker. The equivalent manual Terminal commands are:

  cd "$HOME/Downloads"
  echo '0e567d4ec6f6927f1879a4ec78cc46455d4a04e15fab436b381f55fdb50995fc  WarRoomBot-20261015.1-source.zip' | shasum -a 256 -c -
  mkdir -p warroombot-update-20261015.1
  unzip -q WarRoomBot-20261015.1-source.zip -d warroombot-update-20261015.1
  /usr/bin/python3 -u warroombot-update-20261015.1/WarRoomBot/tools/apply_activity_runtime_update.py --archive "$HOME/Downloads/WarRoomBot-20261015.1-source.zip" --sha256 0e567d4ec6f6927f1879a4ec78cc46455d4a04e15fab436b381f55fdb50995fc --choose-workbook

If workbook selection is canceled, the Python update remains applied. Reopen
the picker later with:

  "$HOME/WarRoomBot/.venv/bin/python" "$HOME/WarRoomBot/tools/choose_activity_log.py"

The old app's Set up / Update / Repair restores its bundled Python files.
Reapply the runtime update after using that action. The updater refuses unknown
installed versions and unexpected local code edits; it backs up original files
and rolls back a failed file update.
